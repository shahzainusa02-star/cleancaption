# Privacy

CleanCaption v1.0 Beta is designed for local processing.

- Selected videos are processed on the user's own computer.
- The CleanCaption application code does not send uploaded videos to a CleanCaption server.
- The application does not require a CleanCaption account or API key.
- The first launch may use the internet to download required Python packages from package repositories.
- Temporary processing files are created in the operating system's temporary directory.

Users remain responsible for the videos they process and for complying with applicable
copyright, privacy, platform, and other legal requirements.
