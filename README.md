# CleanCaption v1.0 Beta

CleanCaption is a local macOS caption-removal utility.

## Current beta scope

This release is optimized for centered white burned-in captions with a dark outline in
the lower-middle area of portrait videos. It is not yet a universal subtitle remover.

## Privacy

Videos are processed locally by the application. See `PRIVACY.md`.

## Download

Use the latest GitHub Release and download `CleanCaption-v1.0-macOS.zip`.

## macOS first launch

Because this free beta is not Apple-notarized, macOS may require:
**Right-click `Start CleanCaption.command` → Open**.

## Requirements

- macOS
- Python 3
- FFmpeg

## Repository layout

- `app/` — CleanCaption application source
